# ELOS Future Enhancements

## High Priority (User Experience)

### 1. Notification Bell with Unread Count (IMPLEMENTING)
Add a notification bell icon in the header with a badge showing unread message count.

### 2. Password Reset / Forgot Password
Users currently cannot reset their own password if they forget it. Add a Forgot Password link on login page with email verification.

### 3. Order Cutoff Time Enforcement (IMPLEMENTING)
Prevent employees from ordering after the cutoff time (e.g., 10:00 AM for lunch). Critical for kitchen planning.

### 4. Email Notifications
Send email notifications for: new user accounts, order confirmations, order ready, messages received.

## Medium Priority (Functionality)

### 5. Dashboard Analytics
Order trends, popular dishes, company breakdown, kitchen efficiency metrics.

### 6. Menu Planning Calendar
Weekly/monthly calendar view for kitchen staff to plan menus in advance.

### 7. Employee Order History and Favorites
Let employees see order history and quickly re-order favorites.

### 8. Dietary Preferences Auto-Filter
Auto filter/highlight suitable menu items based on employee dietary preferences.

### 9. Order Modifications
Allow employees to modify or cancel orders before cutoff time.

### 10. Bulk User Import
HR can upload CSV file to create multiple employees at once.

## Lower Priority (Nice to Have)

### 11. Mobile App / PWA
Make the app installable on phones.

### 12. Multi-language Support
Implement actual translations (English/Spanish).

### 13. Feedback and Ratings
Let employees rate meals and provide feedback tied to menu items.

### 14. Print Kitchen Labels
Generate printable labels for each order.

### 15. Calendar Integration
Sync lunch orders with employee calendars (Google/Outlook).
